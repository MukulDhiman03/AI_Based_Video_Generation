# VidSutra.ai UI review

Stitch project: https://stitch.withgoogle.com/projects/4861852220232106174

These are design mockups for review. They do not implement application flows, connect Instagram accounts, send invitations, or publish posts.

## Visual direction

- Dark theme only; no light-mode control.
- Charcoal canvas `#090B12`, raised surfaces `#141824`, subtle borders `#282D3F`.
- Lavender primary `#A69BFF`, mint status `#75E3BE`, warm amber warnings.
- Manrope headings, Inter body, and Noto Sans Devanagari for Hindi.
- Shared studio navigation, restrained cards, and responsive mobile compositions.

## Product boundaries

Phase 1 covers invite-only free beta access, English/Hindi animated explainer reels (30/60/90 seconds), single-image posts, ideas, library, whole-content regeneration, preview, download, and explicit Instagram publishing or scheduling. Narration is restricted to Viraj Energetic & Confident and Monika Sogam Deep & Natural.

There is no timeline or scene editor, per-scene regeneration, background music, paid plan, team workspace, social analytics, or additional social network in the design brief. Previous completed output remains available when a replacement is generated.

## Review notes

Sample content, accounts, dates, usage, and administration data are illustrative. Quota values and reset timing are not policy commitments. Taglines, image-aspect choices, and caption presentation are design proposals. Privacy and Terms screens are draft layout placeholders; final legal copy is required before launch.

Generated screens still require product review. In particular, check wording against the agreed scope and avoid treating generated labels, promises, or metrics as approved requirements.

The set covers 30 named screens: 22 product/public/authentication/legal views, 3 administration views, 4 mobile layouts, and 1 feedback view. Stitch also retains 5 earlier screen versions from the targeted cleanup pass. Use the latest five-screen row for Overview, Generation Progress, User Settings, Mobile Overview, and Mobile Publishing.

`screens.json` records the 30 current screen selections. `screen-versions.json` preserves all 35 saved screen resources. `previews/` contains the current screenshots; `previews/versions/` preserves each resource separately. `stitch-canvas.png` captures the review project in the browser.
